# Социальные функции ProjectF

Идея направления: превратить ProjectF из личной читалки в пространство, где можно читать вместе, обсуждать книги без спойлеров, делиться заметками и находить людей со схожими интересами.

Этот документ описывает возможное развитие. Пункты не входят в текущий план разработки, пока не перенесены в основной список задач.

## Приоритет 1 — публичный профиль и приватность

- [ ] Добавить уникальное имя пользователя для поиска и ссылок на профиль.
- [ ] Настроить видимость профиля: публичный, только для друзей или закрытый.
- [ ] Разрешить отдельно скрывать библиотеку, статистику, активность и список друзей.
- [ ] Показывать в публичном профиле аватар, описание, любимые жанры и выбранные книги.
- [ ] Добавить чёрный список пользователей.
- [ ] Не раскрывать точную позицию чтения и личные заметки без явного разрешения владельца.

## Приоритет 2 — друзья и подписки

- [ ] Добавить поиск пользователей по имени.
- [ ] Добавить заявки в друзья: отправка, принятие и отклонение.
- [ ] Показывать входящие и исходящие заявки.
- [ ] Разрешить удалять пользователя из друзей.
- [ ] Добавить подписки на открытые профили без взаимного добавления в друзья.
- [ ] Показывать общие книги и пересечение жанров.
- [ ] Добавить короткий список активности друзей с учётом настроек приватности.

## Приоритет 3 — личные и групповые чаты

- [ ] Добавить личный чат между друзьями.
- [ ] Добавить групповые чаты с названием, аватаром и списком участников.
- [ ] Поддержать ответы на сообщения, редактирование и удаление своих сообщений.
- [ ] Показывать непрочитанные сообщения и время последнего прочтения.
- [ ] Добавить поиск по сообщениям.
- [ ] Разрешить отправлять ссылку на книгу, главу, закладку или цитату.
- [ ] Скрывать цитаты из непрочитанной части книги предупреждением о спойлере.
- [ ] Добавить жалобу, блокировку и ограничение нежелательных сообщений.
- [ ] Отдельно спроектировать шифрование переписки и управление ключами до начала реализации вложений.

## Приоритет 4 — сообщества

- [ ] Разрешить создавать открытые и закрытые сообщества.
- [ ] Добавить название, описание, обложку, правила и тематические теги.
- [ ] Добавить роли владельца, администратора, модератора и участника.
- [ ] Реализовать вступление, заявки и приглашения.
- [ ] Добавить каналы или разделы сообщества: новости, общий чат, обсуждения и рекомендации.
- [ ] Разрешить закреплять сообщения, публикации и текущую книгу сообщества.
- [ ] Добавить каталог и поиск сообществ по жанрам и книгам.

## Приоритет 5 — новости и публикации

- [ ] Добавить ленту публикаций друзей и сообществ.
- [ ] Поддержать короткий текст, изображение, цитату, книгу и список книг.
- [ ] Добавить комментарии и ответы на комментарии.
- [ ] Добавить реакции и сохранение публикаций.
- [ ] Поддержать упоминания пользователей и сообществ.
- [ ] Добавить предупреждение и скрытие спойлеров.
- [ ] Разделить обычные публикации и официальные новости сообщества.
- [ ] Позволить пользователю выбирать между общей и хронологической лентой.

## Приоритет 6 — книжные клубы и совместное чтение

- [ ] Создавать совместное чтение выбранной книги внутри сообщества.
- [ ] Задавать дату начала, расписание и цель по главам или проценту.
- [ ] Показывать общий прогресс без раскрытия точной позиции отдельных участников.
- [ ] Создавать обсуждения, привязанные к главе или диапазону текста.
- [ ] Скрывать обсуждения более поздних глав от ещё не дочитавших пользователей.
- [ ] Добавить голосования за следующую книгу.
- [ ] Добавить календарь встреч и обсуждений.
- [ ] Формировать общий итог чтения из добровольно опубликованных заметок и цитат.

## Приоритет 7 — рекомендации и поиск

- [ ] Искать книги, пользователей, публикации и сообщества из одного окна.
- [ ] Рекомендовать сообщества по книгам и жанрам из библиотеки пользователя.
- [ ] Показывать популярные обсуждения без раскрытия спойлеров.
- [ ] Добавить пользовательские подборки книг с описанием и обложкой.
- [ ] Разрешить подписываться на подборки и копировать их книги в список «Хочу прочитать».
- [ ] Не использовать личные заметки и закрытую активность для рекомендаций.

## Приоритет 8 — уведомления

- [ ] Добавить центр уведомлений внутри приложения.
- [ ] Уведомлять о заявках в друзья, сообщениях, ответах, упоминаниях и событиях клуба.
- [ ] Разрешить отключать каждый тип уведомлений отдельно.
- [ ] Добавить режим «Не беспокоить».
- [ ] Объединять повторяющиеся события, чтобы не создавать поток одинаковых уведомлений.
- [ ] Позже предусмотреть добровольные email-уведомления и недельный дайджест.

## Приоритет 9 — безопасность и модерация

- [ ] Добавить жалобы на пользователя, сообщение, комментарий, публикацию и сообщество.
- [ ] Создать очередь жалоб для модератора.
- [ ] Добавить временную блокировку публикаций и отправки сообщений.
- [ ] Ограничить частоту заявок, сообщений и публикаций для защиты от спама.
- [ ] Вести журнал действий модераторов.
- [ ] Добавить удаление своих социальных данных и экспорт переписки.
- [ ] Проверить защиту от XSS, вредоносных ссылок и опасных вложений.
- [ ] Определить возрастные ограничения и правила публикации контента до публичного запуска.

## Приоритет 10 — техническая основа чатов

- [ ] Использовать WebSocket для доставки сообщений и событий в реальном времени.
- [ ] Сохранять сообщения до отправки события, чтобы они не терялись при сбое соединения.
- [ ] Добавить идентификатор клиентской операции для защиты от дублирования сообщений.
- [ ] Поддержать постраничную загрузку старой переписки.
- [ ] Синхронизировать непрочитанные сообщения между несколькими устройствами.
- [ ] Показывать состояния подключения, повторной отправки и ошибки.
- [ ] Добавить локальную очередь сообщений при временной потере сети.
- [ ] Хранить вложения отдельно от текста сообщений и проверять их тип и размер.
- [ ] Добавить метрики доставки без сохранения содержимого сообщений в технических логах.

## Рекомендуемый социальный MVP

Для первой рабочей версии достаточно следующего набора:

1. Публичное имя и базовые настройки приватности.
2. Поиск пользователей и заявки в друзья.
3. Личный чат между друзьями без файловых вложений.
4. Отправка ссылки на книгу или цитату с защитой от спойлеров.
5. Непрочитанные сообщения и центр уведомлений.
6. Блокировка пользователя и жалоба на сообщение.

Сообщества, общую ленту и книжные клубы лучше строить после проверки личных чатов. Их модели ролей, публикаций и модерации значительно увеличат объём backend-логики и интерфейса.

## Возможная структура основного меню

- **Библиотека** — личные книги.
- **Документы** — рабочие материалы и контексты.
- **Общение** — друзья, личные и групповые чаты.
- **Сообщества** — клубы, новости и тематические обсуждения.
- **Уведомления** — заявки, сообщения, ответы и события.
- **Профиль** — публичные сведения, статистика и приватность.

На мобильных устройствах раздел «Общение» может объединять друзей и чаты в одном экране, чтобы не перегружать боковую навигацию.
