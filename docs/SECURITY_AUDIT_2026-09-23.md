# Проверка безопасности BookMind — 23.09.2026

Проверены маршруты Spring Security, авторизация доступа к книгам, документам, чатам, контекстам и загрузкам, обработка файлов, вывод пользовательского текста и ответы AI, сессии, прямые зависимости и разрешённые runtime-зависимости. Это проверка кода и тестовой среды; она не заменяет проверку развёрнутого сервера и внешней сети.

## Исправлено

- Иллюстрации из EPUB/FB2 могли сохраняться с типом `image/svg+xml` и выдаваться с того же домена, что и приложение. Для ответов с изображениями теперь добавлены `Content-Security-Policy: sandbox`, `X-Content-Type-Options: nosniff`, а SVG при прямом открытии выдаётся как вложение. Добавлен тест для SVG и обычного PNG.
- Spring Boot обновлён с 4.0.2 до 4.0.8, jsoup — с 1.21.2 до 1.23.1, встроенный Tomcat — до 11.0.26. До обновления OSV находил advisory для 21 из 110 разрешённых Maven-пакетов; после обновления — 0 из 110. Совпадение advisory с версией не означает применимости каждого сценария к BookMind.
- Добавлены проверки, что второй аккаунт не может получить обложку, иллюстрацию, сохранённый контекст или чужую upload session.

## Осталось сделать

1. **Высокий приоритет — лимиты платных операций.** `BookChatController.send` принимает разные ID запросов параллельно и не ограничивает число запросов на пользователя или в сутки. Изложения ограничивают одновременную работу на одном документе, но не общий бюджет аккаунта. Нужны атомарная квота и ограничение параллельности на сервере; только блокировка кнопки в UI не защищает API.
2. **Высокий приоритет — защита входа от перебора и нагрузки.** `/api/auth/login` и `/api/auth/register` доступны анонимно; в коде нет ограничения частоты по IP/аккаунту. Хеширование PBKDF2 делает проверку пароля дорогой и для сервера. Нужны лимиты на уровне reverse proxy и приложения, с аккуратным учётом общих IP.
3. **Средний приоритет — ограничение тяжёлой обработки.** Загрузка ограничена 30 МБ; EPUB дополнительно ограничен по распакованному объёму, числу файлов и размеру записи, а XML внешние сущности отключены. Но синхронный импорт PDF/DOCX и вызов конвертера DOCX из GET `/api/books/{id}/preview` могут запускаться одновременно без лимита на пользователя; один конвертер может работать до 60 секунд. Нужны очередь, квоты и кэширование/блокировка повторной конвертации.
4. **Средний приоритет — длинная сессия.** Токен «Запомнить меня» хранится в базе как SHA-256 и выдаётся на 30 дней, но при восстановлении сессии не ротируется. Украденный токен действует до истечения срока или отзыва. Стоит ротировать его после успешного использования.
5. **Перед публикацией — проверить окружение.** Убедиться, что сайт работает только через HTTPS, оба session-cookie имеют `Secure`, прокси корректно передаёт схему, CORS и заголовки безопасности соответствуют реальному домену, а логи и резервные копии закрыты. Значения секретов в рамках этой проверки не читались.

## Подтверждено проверками

- API требует входа; проверенные маршруты возвращают 404 на чужие ID. Тесты используют отдельные аккаунты и PostgreSQL в Testcontainers.
- CSRF включён; клиент посылает токен на изменяющие запросы. Вход меняет ID сессии. Пароли хранятся через PBKDF2.
- Текст книги и ответ Книжника отображаются React как текст, без `dangerouslySetInnerHTML`; в проверенных компонентах нет вставки сырого HTML.
- `npm audit` для всех frontend-зависимостей: 0 найденных advisory. OSV batch-запрос по 110 runtime Maven-пакетам после обновления: 0 найденных advisory на дату проверки. Базы advisory неполны и меняются со временем.
- `gradlew test` пройден после обновления зависимостей; новые проверки разграничения доступа также пройдены. Реальные запросы к DeepSeek не выполнялись.
